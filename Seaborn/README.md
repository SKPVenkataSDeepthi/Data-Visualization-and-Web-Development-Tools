# Seaborn Data Visualization

This folder contains various Seaborn visualizations and utilities for data visualization in Python. Seaborn is a powerful library built on top of Matplotlib that provides a high-level interface for drawing attractive and informative statistical graphics.

### Key Components:
- **Plotting Functions**: Includes commonly used plotting functions such as `scatterplot`, `lineplot`, `histplot`, `heatmap`, `boxplot`, `violinplot`, and more.
- **Statistical Plots**: Functions like `lmplot`, `regplot`, `residplot`, `pairplot`, and `catplot` for creating statistical relationships between variables.
- **Themes and Styles**: Functions like `set_theme`, `set_style`, and `set_context` for customizing the appearance of plots.
- **Color Palettes**: Various color palette options like `husl_palette`, `cubehelix_palette`, and `xkcd_palette` for enhancing visual aesthetics.
- **Advanced Plotting**: Includes objects and utilities like `seaborn.objects.Plot`, `seaborn.objects.Dot`, `seaborn.objects.Line`, and more for detailed control over plot creation.
