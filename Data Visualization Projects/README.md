# Data Visualization Projects

This repository contains a collection of five data visualization projects built using **D3.js**, **APIs**, and **AJAX** technologies. These projects are part of the **FreeCodeCamp Data Visualization Certification**. Each project demonstrates the application of D3.js to fetch, parse, and visualize datasets in various formats.

---

## Certification
Completing these projects fulfills the requirements for the **FreeCodeCamp Data Visualization Certification**, showcasing proficiency in D3.js and data visualization techniques.

---
## Technologies Used
- D3.js: For creating dynamic and interactive visualizations.
- APIs and AJAX: For fetching and parsing data from external sources.
- HTML, CSS, JavaScript: For structuring and styling the projects.
