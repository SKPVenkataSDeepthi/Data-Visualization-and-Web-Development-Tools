# 🚀 How to Run the Dashboards

## Step 1: Clone the Repository

```bash
git clone https://github.com/SKPVenkataSDeepthi/Data-Visualization-and-Web-Development-Tools.git
```

---

## Step 2: Open the Project in RStudio

Open the required dashboard folder inside RStudio.

---

## Step 3: Install Required Packages

```r
install.packages(c(
  "shiny",
  "shinydashboard",
  "ggplot2",
  "plotly",
  "dplyr",
  "DT",
  "tidyverse"
))
```

---

## Step 4: Run the Dashboard

Open the `app.R` file and click:

▶️ **Run App**

OR

Run using:

```r
shiny::runApp()
```
